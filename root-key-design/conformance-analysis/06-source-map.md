# 06. 원문 위치 대응표

각 ID는 고정 원문의 **파일·줄 범위·절 제목**으로 연결된다. 줄 번호는 `git show`로 읽은 Git blob 기준이며 수정된 checkout이나 PDF 텍스트 추출 결과의 줄 번호가 아니다. 표는 출처 안내다. 의무 수준과 적용 조건은 01–05의 해당 ID에서 읽고, 판단 근거는 연결된 원문에서 확인한다.

[source-manifest.json](source-manifest.json)은 원문 33개 파일의 저장소 경로·커밋·Git blob ID·SHA-256을 담는다. [requirement-source-map.json](requirement-source-map.json)은 아래 96개 ID의 source ID·줄·절·확인점·직접 링크 및 줄 묶음의 LF 정규화 SHA-256을 담는다. 해시와 링크 검사는 내용 해석을 대신하지 않는다.

프로파일 파일명은 `conformance-public/docs/v0.2/cert-profiles/` 아래의 원문이다. Conformance 자료는 `2466172859fad1215f7aaf7e3768b41a0ac29abc`, Spec 자료는 `9c58c8c27044e44e8601f6ab13f1bcac1376eb1f`로 고정했다. CA·leaf YAML 총 8개의 CP 내장 블록과 별도 파일은 양끝 공백을 제외하고 동일함을 확인했다. JSON certificate/CSR schema를 이 YAML과 동일하다고 가정하지 않는다.

Q03은 Spec이 규범 참조하는 [RFC 5280 §4.2.1.1](https://www.rfc-editor.org/rfc/rfc5280.html#section-4.2.1.1)·[§4.2.1.2](https://www.rfc-editor.org/rfc/rfc5280.html#section-4.2.1.2)도 RFC Editor에서 직접 확인했다(2026-10-08). 발급자 CA SKI를 그 CA가 발급하는 인증서의 AKI keyIdentifier에 넣는 규칙이 있다. 이는 별도 보충 원문이며 Git 원문 33개·해시 검증에 포함하지 않는다.

## 원문 읽기 재현

저장소 루트에서 실행한다. `git show`는 checkout 내용을 바꾸지 않는다. 새 환경의 원문 확보 방법은 `references/sources.md`를 따르되 목록 자체는 규범 근거가 아니다.

```sh
git -C conformance-public show '2466172859fad1215f7aaf7e3768b41a0ac29abc:docs/v0.2/C2PA Certificate Policy.md' | nl -ba | sed -n '779,813p'
git -C conformance-public show '2466172859fad1215f7aaf7e3768b41a0ac29abc:docs/v0.2/C2PA Certificate Policy.md' | sha256sum
git -C specifications show '9c58c8c27044e44e8601f6ab13f1bcac1376eb1f:build/site/specifications/2.4/specs/C2PA_Specification.html' | nl -ba | sed -n '4595,4772p'
```
