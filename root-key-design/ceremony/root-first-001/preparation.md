# Root와 First ICA 세레모니 — 준비 현황

작성 중 · 실제 환경·담당자·일정·명령·리허설·승인은 미확정입니다. 행사별 준비 상태는 이 문서에서 관리합니다. 공통 확인 항목은 [준비 체크리스트](../preparation-checklist.md), 작성 방법은 [가이드](../script-writing-guide.md)를 참고합니다.

[2026-10-11 C2PA v0.2 적합성 검토](c2pa-review-2026-10-11.md): C01–C08의 원문 대조와 미해결 조건을 확인합니다. FIPS 저장 문구, 생성 통제, 인증서·CSR 필드와 schema 차이, First 상태 제공 시점을 우선 해결해야 하며 현재 초안은 준수 완료 판정이 아닙니다.

## 설계 보류와 후속 결정

2026-10-12 S00 자료 양식 작성: [materials/s00](materials/s00/README.md)에 자료 5종의 준비 담당·작성 시점·필수 기재사항·첨부 증거를 작성했다. 승인값·실제값, 사전 시험·당일 조회, 생성 전 계획·생성 후 확인을 구분한다. 가이드의 M01-01–M05-04 검토 항목과 S00 기록지의 자료별 판정에 연결했다. 실제 자료는 미작성이고 인적 사항·환경·수치 기준·시험 결과·승인은 기존 미정/미실시 상태다.

2026-10-12 기록·지시 분리: `records/`의 수행 절차·자료 준비 설명·통과/중단 조건은 담당자 가이드로 이동했다. 기록지는 작성 안내·실제 결과·근거·판정·서명란을 유지한다. 보류·재개 지시는 script와 가이드에, 실제 판단 기록은 전용 기록지에 둔다. 호출 번호별 표는 본문 기록 항목의 대응표이며 중복 작성란이 아니다. 손서명 대상의 새 정책을 확정한 변경은 아니다.

[스크립트](script.md)는 제출용 상세 절차서의 본문과 낭독 지시를 함께 담는다. [담당자 가이드](guides/README.md)는 행동·확인 기준을 담는 승인 부속 문서이며, [단계별 기록지](records/record-template.md)는 실제 결과·판정·적용 절차와의 일치/일탈을 담는다. 현재 공통 구조와 S00만 이 형식으로 정리했으며 S01–S07 상세 연결·수행 확인 서명 대상 정리는 후속 작업이다. 추후 결정·구현 상태·선택 근거는 이 문서와 연결된 설정표에서 관리한다. 개발 구현 상세는 후속 작성으로 미루되 행사 전 구현·검증·리허설 조건은 유지한다.

2026-10-12 사용자 지시: **인쇄 묶음의 최종 작성은 문서 내용 확정 후 마지막 단계에 수행한다.** 현재는 진행·역할·기록 내용과 손서명/일반 기록의 구분을 먼저 정리한다. 기존 `print/` 산출물은 검토용 이전 초안으로 보존하며 이후 원문 변경을 실시간 반영하거나 배부본으로 사용하지 않는다. 최종 작성 시 전체 재생성·인쇄 점검·승인을 수행한다. 기존 모든 기록란의 `이름/확인 서명` 표시는 항목별 손서명 의무를 확정한 것이 아니다.

## CSR·인증서 사전 고정과 당일 작성

**현재 작성에서는 개발 구현 상세를 후속으로 미룬다.** 타 부서 협의에서는 승인 정책·역할·준비 완료 기준을 우선한다. 아래 표는 후속 개발 준비 항목이며 지금 도구나 명령을 선정하지 않는다. 생성 도구·명령·설정 템플릿은 행사 전에 준비·검토·리허설하고 버전과 해시를 고정한다. **당일 작성 대상은 사전 고정한 템플릿에 실제 생성값을 반영한 실행용 설정과 CSR·인증서 본문**이다. 아래 시점 구분은 준비 계획이며 실제 도구·명령 선정이나 시험 완료를 뜻하지 않는다.

| 항목 | 행사 전에 확정·검증 | 당일 해당 단계에서 작성·확인 |
|---|---|---|
| 본문 생성 도구·설정 | 생성 코드/도구·의존성·버전, 설정 템플릿과 입력 규칙, 프로파일 검사, 승인본 해시 | 승인본과 일치하는지 확인하고 실제 값으로 실행용 설정 생성. 생성한 설정·본문의 해시 기록 |
| 이름·기간·URL | DN·URL, 유효기간 시작 기준·기간 계산 규칙을 해당 본문 작성 전 승인 | 승인된 값을 사용하고 실제 notBefore/notAfter 시각을 서명 전에 고정. 당일 입력은 새 정책 선택이나 URL 기능 구현을 뜻하지 않음 |
| 생성·계산 값 | 공개키 취득, Serial 생성·예약, SKI/AKI 계산 방법과 도구 | HSM 공개키 취득, Serial 생성·원장 예약, SKI/AKI 계산·연결 검사 |
| HSM 서명 입력 | raw/digest 선택, CLI 버전·정확한 옵션·명령, 단일 해싱 검사와 리허설 | 고정 본문 또는 그 digest를 승인하고 정해진 명령 실행 |
| 서명 변환·조립 | HSM 출력 형식, DER 변환·최종 조립 코드와 명령, 원본 응답에서 재조립하는 절차 검증 | 원본 서명 응답 보존, 승인된 코드로 CSR·인증서 조립 |
| 파일 경로·이름 | 작업/증거 디렉터리·권한·명명 규칙, 작업 ID 등 치환 변수, 덮어쓰기 방지 | 승인된 규칙으로 해당 회차의 실제 경로·파일명 확정 및 기록 |
| 독립 검증 | 검증 도구·버전·명령·판정 기준, 테스트 키로 정상/거부 사례 확인 | 실제 CSR 서명, 인증서 서명·체인·DER·확장·공개키 연결을 검증하고 증거 저장 |

First CSR은 AIA/CDP 없이 필수 3개 요청 확장으로 작성하고, First 인증서 본문 생성 시 승인한 AIA를 추가한다. [규격 근거](settings.md#first-csr-설정)를 따른다. 당일 생성값은 각 단계의 서명 전에 본문과 함께 검토·승인한다. 도구·버전·템플릿·명령을 변경하면 영향 검토·필요한 재시험·재승인을 거친다. OCSP·URL 제공 기능은 현재 미구현이며 기존 S05 발급 전 준비 조건을 유지한다.

## 적용 기준과 범위

- **행사와 키 통제:** CP의 「Key Pair Generation and Installation by CAs」, 「Controls for CA Keys」 및 관련 역할·기록 통제를 두 CA의 생성과 발급 절차에 반영한다. Root 작업을 같은 통제·증거 묶음에 포함하는 것은 이번 행사의 프로젝트 선택이다.
- **인증서와 CSR 검사:** CP의 「Certificate Profiles for Certification Authorities」와 Root·First YAML을 대조해 설정을 작성한다. Root 인증서, First 인증서, First CSR의 검사에는 각각 대응하는 schema를 사용한다. schema 검사와 별도로 실제 서명·키 연결·인증서 체인을 검증한다.
- **향후 등록 증거:** Program의 「Certificate Policy」와 「Certification Authority Evidence Request」를 기준으로 First 인증서의 프로파일 검사와 독립 입회·서명된 키 생성 스크립트의 증거를 준비한다. 이번 행사에서는 독립 입회 방식으로 준비하며, 외부 신청과 심사 판정은 후속 작업이다.

기준 문서의 선택은 완료했으며, 개별 조항과 실제 설정·담당자·명령·증거의 대응은 [준비 현황](preparation.md#먼저-정할-사항)의 P02–P06에서 구체화한다. CP 본문·YAML·schema 사이의 차이나 해석이 필요한 사항은 P04에 기록하고 발급 전에 해결 근거를 검토한다. 원문 고정본의 commit과 파일 해시는 사용한 자료를 식별하기 위한 프로젝트 기록이며, C2PA의 별도 규격 버전이나 행사 승인 기록을 뜻하지 않는다.

First ICA의 C2PA Trust List 등록은 후속 계획이며 외부 등록 신청·심사 판정은 이번 행사 범위에서 제외한다.

이번 5명 배치는 프로젝트의 기본안이며 C2PA가 정확히 5명을 지정한다는 뜻은 아니다. 업무량·적격성에 따라 지원 업무를 분리할 수 있으나 실행/검증 분리와 입회자 독립성은 유지한다. 역할 정의와 겸임 배치는 프로젝트 정책이며, 원문의 책임 정의·직무 분리 근거는 [CP의 CA 키 생성](https://github.com/c2pa-org/conformance-public/blob/2466172859fad1215f7aaf7e3768b41a0ac29abc/docs/v0.2/C2PA%20Certificate%20Policy.md#key-pair-generation-and-installation-by-cas), [직무 분리](https://github.com/c2pa-org/conformance-public/blob/2466172859fad1215f7aaf7e3768b41a0ac29abc/docs/v0.2/C2PA%20Certificate%20Policy.md#separation-of-duties)에 연결한다.
