Independent Witness 인쇄 책자

자기 책자의 현재 단계만 펼칩니다. 진행자가 “단계.번호, 업무”를 부르면 해당 행을 찾습니다. 먼저 수행하지 않습니다.

공용 기록지의 같은 번호·본인 이름 칸에 직접 기록합니다. 끝나면 “S01.2, Key Custodian 2, 완료”처럼 번호·담당·결과를 말합니다. 이상은 즉시 중단 요청합니다.

입회자는 단계 전체를 관찰합니다. 대기 표시는 역할 해제나 퇴장을 뜻하지 않습니다. 단계 종료와 다음 단계 이동은 Administrator가 선언합니다.

종이 확인 서명은 생성 계획·HSM 토큰의 전자서명을 대신하지 않습니다. 개인 승인키는 승인된 장치에서 본인이 사용합니다.

Independent Witness 담당자 가이드

초안 · 당신은 승인된 범위를 독립적으로 관찰하고 실제 수행과 기록의 일치를 확인합니다. 다른 행사 역할을 겸하지 않으며 생성/서명 실행·quorum 승인·운영 자격증명/승인키 보관은 하지 않습니다. 기술 검증이나 시작·완료 승인을 대신하지 않습니다.

시작 전에 임명·적격성/교육·독립성·관찰 범위와 접근 방법을 확인합니다. 관찰이 끊기거나 필수 절차를 볼 수 없으면 즉시 중단을 요청합니다. 이후 기록만 보고 관찰했다고 서명하지 않습니다. 공통 규칙 — 책자 앞면의 역할 규칙을 따릅니다.
