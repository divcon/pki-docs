공용 기록지의 같은 번호·본인 이름 칸에 직접 기록합니다. 끝나면 “S01.2, Key Custodian 2, 완료”처럼 번호·담당·결과를 말합니다. 이상은 즉시 중단 요청합니다.

입회자는 단계 전체를 관찰합니다. 대기 표시는 역할 해제나 퇴장을 뜻하지 않습니다. 단계 종료와 다음 단계 이동은 Administrator가 선언합니다.

종이 확인 서명은 생성 계획·HSM 토큰의 전자서명을 대신하지 않습니다. 개인 승인키는 승인된 장치에서 본인이 사용합니다.

역할 정의와 허용·금지 행위

담당자 가이드의 역할 정의 — 책자 앞면의 역할 규칙를 적용합니다. 각 담당자의 행동·금지 행위와 기록 위치는 명부에 연결된 개인별 가이드에서 확인합니다.

직무 분리와 겸임 규칙

공통 직무 분리·겸임 규칙 — 책자 앞면의 역할 규칙을 적용합니다. 실행과 검증을 분리하고 Independent Witness는 다른 역할을 겸하지 않습니다.

다자 통제의 적용과 확인

생성은 앱이 검증한 생성 계획 승인, 인증서/CSR 서명은 작업별 CloudHSM quorum을 사용하며 각각 같은 세 보유자 중 서로 다른 2명 이상이 승인합니다. 시작/다음 단계 판정은 이 승인을 대신하지 않습니다. 통제별 역할 — 책자 앞면의 역할 규칙을 따릅니다.

종이로 진행하는 방법

  • 진행자는 “S01.2, 생성 계획 승인”처럼 단계·호출 번호·업무를 소리 내어 알리고 현재 번호를 공용 진행판에 표시합니다.
  • 각자는 자기 가이드의 같은 단계에서 번호를 찾습니다. 수행 / 대기 / 계속 관찰 표시를 따릅니다. 단순히 다음 페이지를 넘겼다고 실행하지 않습니다.
  • 기록 원본은 단계별 한 묶음만 사용합니다. 공용 기록대에서 해당 작성자가 같은 번호의 본인 칸에 직접 기록하고 돌려놓습니다. 개인 책자 메모는 공식 기록을 대신하지 않습니다.
  • 종이 확인은 실제 행위와 근거의 기록입니다. 생성 계획/토큰의 전자서명은 승인된 장치·앱으로 별도 수행합니다. 개인별 노트북이 있다고 가정하지 않으며, 장치 배정은 승인 실행 환경을 따릅니다.
  • 값·검사 자료·출력 원문은 사전 배부한 자료 묶음이나 승인된 작업 화면으로 제시합니다. 인쇄본만으로 미확정 명령·설정을 대신하지 않습니다. 중단은 누구나 요청할 수 있고 재실행은 임의로 하지 않습니다.

당일 사용할 설정과 실행 절차

  • Administrator는 시작 전 확인 — 별책「시작 전 준비 확인」과 승인본 목록을 확인하고 같은 버전의 가이드·설정·runbook·기록 양식을 배부합니다.
  • 회차 목록에 실제 기록지 사본을 연결합니다. 각 단계가 끝나면 그 기록을 닫고 다음 단계의 기록지를 엽니다.
  • 단계 안에서는 준비 → 사전 확인·개별 승인 → 실행 → 독립 검사·입회 기록 → 진행 판정 순서를 지킵니다. 역할별 기록은 해당 담당자가 남기며 서명 기록은 덮어쓰지 않습니다.

S00.1 진행자 발언

전원 자기 책자의 S00을 펴세요. 지금 S00.1입니다. 행사 ID·회차·인쇄 묶음 ID와 승인본을 확인하겠습니다. Witness는 입회 시작·관찰 범위를 알려 주세요. 아직 키를 생성하지 않습니다.

  • 다음 호출 조건: 행사·수행 승인본·기록 원본 묶음이 식별되고 Witness가 관찰 가능한 상태에서 입회를 시작했음.
  • 보류·중단: 승인본 또는 자료 1이 없거나 버전이 다름, 원본 기록 묶음 미식별, Witness 관찰 불가.

S00.2 진행자 발언

S00.2입니다. Crypto Officer, Key Custodian 2, Key Custodian 3, Witness 순서로 본인 역할과 책자 ID를 확인해 주세요. 각자 기록한 뒤 Administrator가 명부와 직무 분리를 대조합니다.

  • 다음 호출 조건: 다섯 담당자의 배정·책자 ID·적격성/교육이 대조되고 실행/검증 분리, 서로 다른 세 보유자, Witness 독립성·관찰 조건이 충족됨.
  • 보류·중단: 누락/대리 참석·미승인 겸임/대체·역할/책자 불일치·미확인 교육/적격성·CU/등록키 매핑 불일치.

S00.3 진행자 발언

S00.3입니다. Crypto Officer는 자료 3 환경 대조표, 자료 4 승인 체계·시험표, 자료 5의 로그·저장 시험 결과를 펼쳐 주세요. Administrator는 자료 5의 보관·보호 인수 계획을 제시하겠습니다.

  • 다음 호출 조건: 자료 3–5와 근거 원문을 참가자가 볼 수 있고 버전·조회/시험 시각·승인값/실제값 및 결과가 식별됨. 여기서는 제시 완료만 확인하며 통과 판정은 S00.4에서 함.
