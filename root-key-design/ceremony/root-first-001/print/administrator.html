Administrator 인쇄 책자

자기 책자의 현재 단계만 펼칩니다. 진행자가 “단계.번호, 업무”를 부르면 해당 행을 찾습니다. 먼저 수행하지 않습니다.

공용 기록지의 같은 번호·본인 이름 칸에 직접 기록합니다. 끝나면 “S01.2, Key Custodian 2, 완료”처럼 번호·담당·결과를 말합니다. 이상은 즉시 중단 요청합니다.

입회자는 단계 전체를 관찰합니다. 대기 표시는 역할 해제나 퇴장을 뜻하지 않습니다. 단계 종료와 다음 단계 이동은 Administrator가 선언합니다.

종이 확인 서명은 생성 계획·HSM 토큰의 전자서명을 대신하지 않습니다. 개인 승인키는 승인된 장치에서 본인이 사용합니다.

Administrator 담당자 가이드

초안 · 승인된 명부에서 배정된 담당자만 수행합니다.

진행·독립 검증·기록·운영 인수를 맡습니다. 생성/서명 실행과 quorum 승인, 타인 승인키 보관은 하지 않습니다. 자신의 겸임 업무를 여러 사람의 검증으로 표시하지 않습니다.

시작 전에 본인 역할 임명·교육, 승인된 문서 버전·계정과 필요한 도구를 확인합니다. 모르는 값이나 불일치는 추측해 채우지 말고 중단을 요청합니다. 정책값은 설정표 — 별책「승인 설정」, 실제 명령은 실행 절차 — 별책「실행 절차」, 역할 분리는 공통 규칙 — 책자 앞면의 역할 규칙을 따릅니다.

시작 확인 — 자기 역할의 세부 기준

S00.1에서 자료 1과 기록 원본 묶음을 제시하고, S00.2에서 자료 2를 제시합니다. S00.3에서는 Crypto Officer가 자료 3·4 및 자료 5의 시험 원문을 제시하고, 본인은 자료 5의 보호·보관 계획을 제시합니다. 제시만 끝났다고 통과시키지 않습니다.
