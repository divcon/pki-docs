# 단계별 제시 자료 양식

`materials/`는 단계별 제시 자료의 양식입니다. 사전에 준비할 내용과 제시 전 갱신할 실제값을 구분하고, 수행 중 확인·판정은 records에 작성합니다. 기존 결정값은 상태·근거와 함께 미리 표시합니다. 현재 [S00 시작 확인 자료 5종](s00/README.md)을 작성했습니다. 후속 단계는 필요한 자료를 정한 뒤 추가합니다.

| 문서 | 담당하는 내용 |
|---|---|
| script | 제출용 상세 절차서 본문·진행 순서·낭독 지시·기록 위치 |
| guides | 역할별 수행·검토 방법·판정 기준 |
| materials | 제시할 자료의 형식·필수 기재사항·첨부 증거 |
| records | 당일 실제 결과·판정·근거·작성자·시각·필요한 서명 |

저장소에는 미작성 양식을 관리합니다. 실제 인적 사항·환경 값·시험 원문을 채운 회차 자료는 승인된 보관 위치에서 관리하고 [증거 목록](../evidence-index.md)에 식별 정보를 연결합니다. 같은 승인 문서나 시험 결과를 여러 단계에서 사용할 때는 원본 ID·버전·항목을 참조합니다.

자료 양식 작성은 실제 자료 제출·승인·시험 완료를 뜻하지 않습니다. 인쇄 묶음은 문서 내용 확정 후 마지막에 제작합니다.
