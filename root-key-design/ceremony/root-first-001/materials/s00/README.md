# S00 시작 확인 — 제시 자료 목록

회차별 작성 양식 · 기존 결정값은 미리 표시하고, 미정 값·실제 조회·시험·승인 근거는 담당자가 보완합니다. 자료 1–5는 사전 작성과 제시 전 갱신에 사용하며, 호출 중 확인·판정은 [S00 기록지](../../records/s00-start.md)에 작성합니다. 여기서 ‘제출’은 세레모니 검토자에게 제시한다는 뜻이며 외부 등록 신청이 아닙니다.

## 작성 형식

- 자료 ID·행사/회차·버전·작성자·시각을 표시하고 해당 항목 ID(M01-01 등)를 유지합니다.
- 정책·승인값은 승인된 settings·runbook·역할 명부 등에서 문서 ID·버전·항목과 함께 가져옵니다. 실제 조회·시험 결과는 별도 칸에 적습니다.
- 승인값·시험·담당자가 미정이면 **미정/미실시**와 담당·기한을 적습니다. 빈칸이나 예시를 실제 값으로 취급하지 않습니다. 비적용에는 사유와 적용 판단 근거를 연결합니다.
- 사전 시험 결과와 당일 조회 결과를 구분하고 대상 환경·버전·시각을 함께 표시합니다. 실제값 갱신 시 승인값을 덮어쓰지 않고 변경 이력을 남깁니다.
- 첨부 ID는 문서·파일별 원문 위치·버전·SHA-256·수집자·시각에 연결합니다. 긴 출력은 원문 첨부로 두고 표에는 실제 값과 참조를 적습니다.
- 기존 보고서로 대체할 수 있으나 양식의 필수 항목마다 보고서의 절/페이지를 연결합니다. ‘보고서 참조’만으로 항목 대응을 생략하지 않습니다.
- 자료 자체의 해시는 완성된 파일을 대상으로 별도 파일 목록에 기록합니다. 자료 안에 자기 해시나 이후 확인 서명을 포함해 순환 참조를 만들지 않습니다.
- 손서명과 일반 기록의 구분은 별도 확정 대상입니다. 이 양식은 새로운 손서명 의무나 승인권자를 정하지 않습니다. 기존 행사 승인·전자 승인 증거는 참조로 연결합니다.

## 사전 준비와 현장 확인의 구분

**사전 작성 → 제시 전 갱신 → 호출 중 기록**을 구분합니다. 앞의 두 작업은 자료 1–5에서 작성 시점과 칸을 나누고, 호출 중 기록은 records에 둡니다. 같은 내용을 세 벌 작성하지 않습니다.

| 구분 | 작성할 내용 | 작성 위치 |
|---|---|---|
| 사전 작성 | 기존 결정값 확인, 미정 값 확정, 역할·승인·시험 보고서·보호 계획과 원문 연결 | 자료 1–5의 사전 항목·승인 기준·첨부 목록 |
| 제시 전 갱신 | 실제 배포본·현재 환경·설정·저장 상태, 조회 시각·원문·자료 버전 | 해당 자료의 실제값·첨부·미비점 칸. 승인 기준은 유지 |
| 호출 중 기록 | 실제 제시·참석·검토 결과·이견·보호 인수·선언 | S00 기록지의 담당자별 란. 가이드의 호출별 작성 안내 사용 |

‘실제값’이 모두 호출 중 작성 항목은 아닙니다. 사전 시험의 실제 결과는 행사 전에, 현재 조회 결과는 제시 전에 작성합니다. 운영 키의 속성·백업 포함 여부는 생성 후 S01/S03/S06의 자료와 기록에 연결합니다.

## 이미 정해진 값과 남은 입력

| 표시 | 준비자가 할 일 |
|---|---|
| **결정됨** | 적힌 값을 사용하고 근거 문서·항목을 확인. 회차별 승인본 ID·버전은 연결하되 값을 다시 선택하지 않음 |
| **잠정안** | 제안값을 표시한 채 최종 결정·승인 근거 보완. 결정값이나 실제 설정으로 간주하지 않음 |
| **미정** | 지정 담당자가 행사 전 필요한 값을 결정하고 근거·기한 기록 |
| **제시 전 입력** | 현재 조회·배포 결과와 시각·원문을 채움. 정책값을 그대로 복사하지 않음 |
| **호출 중 기록** | 해당 호출에서 수행한 사람이 records에 실제 결과 기록 |

미리 표시한 값의 기준은 2026-10-12 [settings](../../settings.md)와 [가이드 공통 규칙](../../guides/README.md)입니다. 이 값은 프로젝트 결정의 표시이며 회차별 승인·구축·시험 완료 증거가 아닙니다. 정책 원본은 settings에서 관리하고, 자료는 사용할 승인 버전과 일치시키며 변경 시 함께 검토합니다.

검토 기준은 [Administrator의 자료별 검토 항목](../../guides/administrator.md#s00-자료별-검토-항목)에 있습니다. 실제 판정은 `통과/보류/중단·근거·검토자·시각`으로 records에 한 번만 남깁니다.

현재 실명·환경 식별자·조회 신선도/지연 수치·실행 버전·보존 기간 등은 미정입니다. 관리자/키 관리 quorum·잠금은 잠정안이며 N01/N03 미해결, OCSP·URL 미구현 상태는 [준비 현황](../../preparation.md)에 유지합니다.
