## M04-01 승인 체계·권한 대조

생성 계획 승인과 이후 키 사용 quorum은 각각 별도 증거를 연결합니다. 운영 Root/First 키는 아직 생성 전이므로 키별 속성·quorum의 S00 증거는 **승인된 생성 설정과 테스트 키 시험**입니다. 운영 키 실제값은 S01/S03에서 별도로 기록합니다. 관리자·CU·앱·실행 권한은 현재 환경의 실제 설정을 제시합니다.

|---|---|---|---|
| 생성 계획 앱 승인 | 결정됨: 같은 세 보유자 중 서로 다른 2명, 개인 승인키로 같은 계획에 서명하고 앱이 검증. 1+2·1+3·2+3 허용 / {{승인본}} | {{앱설정_시험}} | {{자료2_연결_명단_경로}} |
| Root/First 키 사용 quorum | 결정됨: 각 2 of 3, key-usage 값 2 / {{승인본}} | {{생성설정_테스트키_시험}} | {{승인집합_등록키}} |
