# 단계별 기록지 — 회차 목록과 사용 방법

미작성 양식 · 기록은 **단계마다 다른 파일**에 남깁니다. 이 파일은 회차 목록이며 S00–S07 내용을 한꺼번에 작성하는 양식이 아닙니다.

## 작성 안내

이 양식은 행사 중 작성해 이후 증거로 보관·제출하는 기록의 목록입니다. 수행 순서·판단 방법은 [스크립트](../script.md)와 [담당자 가이드](../guides/README.md), 회차 준비·원본 관리는 [Administrator 가이드](../guides/administrator.md#기록-준비와-보관)에 있습니다.

- 각 기록에 행사·회차·단계·호출 번호와 작성자·시각을 기입합니다.
- 실제 값·판정·이유를 적고 긴 원문·전자서명·로그는 증거/첨부 번호로 연결합니다.
- 호출 번호별 대응표와 본문에 같은 결과를 중복 기입하지 않습니다. 미작성·미참여·비적용은 해당 상태와 사유를 표시합니다.
- 아래 목록의 실제 기록 ID·위치에는 작성한 회차 사본을 연결합니다. 빈 양식 자체는 수행 증거가 아닙니다.

|---|---|
| 행사 ID·회차·일시·시간대·참석·범위 | {{현장_회차정보}} |
| 승인 묶음 버전·해시 | {{현장_승인본}} |
