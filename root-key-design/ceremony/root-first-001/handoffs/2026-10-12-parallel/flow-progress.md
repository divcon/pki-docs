## S00 연결 재확인 — 2026-10-12

기존 S00-M01–05 양식의 M01-01–M05-04 20개 항목과 Administrator 검토표의 항목 ID가 일치한다. S00.1–.5가 script·다섯 가이드·S00 records에 대응하며, S00.5의 이견 보고 → 실제 선언 → Witness 기록 완료 → 다음 이동 순서를 확인했다. 실제 자료 작성·시험·행사 승인 완료를 뜻하지 않는다.

S01 작성 중 A-001의 S00 자료·공통/개인 가이드·S00 기록지 변경이 같은 작업 폴더에 반영됐다. A 진행 파일에서 사용자 직접 요청 범위를 확인하고 기존 변경을 보존했다. S00 본인 참석은 참석 확인, 준비 확인은 Key Custodians, 자료별 판정은 Administrator, 보호 인수·최종 판정은 다음 단계 판정, 실제 관찰·선언은 Witness 란으로 연결되는지 재검토했다. A의 S00 변경은 B의 S01 작성 실적으로 집계하지 않는다.
