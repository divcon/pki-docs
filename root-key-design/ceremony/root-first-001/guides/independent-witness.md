# Independent Witness 담당자 가이드

## 처음 배정받았다면

**맡은 일:** 승인·실행·검증·인계의 실제 순서를 독립적으로 관찰하고, 관찰한 범위와 제한을 기록합니다.

**먼저 할 일:** Administrator에게 본인 임명·교육 기준, 독립성 확인 자료, 관찰할 단계·현장/화면 접근 방법과 일정을 요청합니다.

**준비 순서:** 독립성·배정 확인 → 관찰 범위·접근 준비 → 기록 방법 연습 → 리허설 → 관찰 가능 여부 확인.

**당일 흐름:** 입회 시작 → 자료·승인·실행·검증 관찰 → 실제 선언 기록 → 본인 관찰 범위 확인.

**역할 범위:** 다른 행사 역할을 겸하지 않습니다. 키 생성·서명 실행·작업 승인·기술 검증·운영 자격증명/승인키 보관을 맡지 않습니다.

## 준비 순서

위에서 아래 순서로 준비합니다. 행사일·담당자·실제 마감일은 아직 미정이므로 Administrator와 확정합니다. ‘현재 상태’는 문서에 기록된 상태이며 본인의 준비 완료를 뜻하지 않습니다.

| 언제 | 내가 직접 할 일 | 받을 자료·요청할 사람 | 완료 근거 · 현재 상태 |
|---|---|---|---|
| 배정 직후 | 본인 임명·교육·독립성·미겸임 확인 | Administrator의 명부·자격/교육 기준·입회 배정 | 임명/교육·독립성 근거 / 실명·일정 미정 |
| 리허설 전 | 어느 단계·화면·기록을 볼지 확인하고 사각지대 알림 | Administrator의 관찰 계획, 현장/화면 접근 지원 담당(미정) | 관찰 범위·방법·제약과 접근 근거 / 상세 계획 미정 |
| 리허설 전 | 호출·개인 승인·실행·검증·선언의 순서와 본인 기록 위치 숙지 | Administrator의 승인 문서 묶음·단계별 공용 기록지 | 누락/중단·실제 선언을 기록하는 방법 확인 / 승인본 미확정 |
| 행사 전 | 리허설에 입회해 실제 관찰 가능 여부와 중단 보고 연습 | Administrator의 일정·진행, Crypto Officer의 테스트 실행 화면 | 관찰 범위·제약·미비점 해소 기록 / 미실시 |
| 행사 전 → 입회 시작 | S00 자료 2의 본인 근거 제공. 접근 변경을 알리고 S00.1에서 관찰 가능 여부 기록 | Administrator의 확정 입회 계획·같은 승인본 | 본인 준비 근거와 실제 관찰 가능 기록 / 실제 자료 미확보 |

HSM 계정·승인키나 기술 시험 보고서를 직접 준비하는 역할은 아닙니다. 관찰 결과는 현장에서 작성하며 아직 보지 않은 작업을 미리 확인하지 않습니다.

## 누구에게 제출·보고하나

- **준비 자료·미정 사항·당일 결과:** Administrator(진행·검증 담당)에게 제출·보고합니다. 자료 검토와 단계 진행·종료 판정도 Administrator가 맡습니다.
- **사전 행사 수행 승인:** 별도 지정 승인권자가 맡으며 현재 미정입니다. Administrator에게 승인 근거를 확인받습니다.
- **작업별 생성·서명 승인:** 세 Key Custodian 중 서로 다른 2명 이상이 합니다. Witness의 관찰이나 진행자의 지시는 이 승인을 대신하지 않습니다.

**보이지 않거나 입회가 끊기면:** 즉시 중단을 요청하고 호출·시각·제한을 기록해 Administrator에게 알립니다. 나중에 기록만 보고 관찰했다고 서명하지 않습니다.

**용어:** Root·First는 이번에 키와 인증서를 만드는 두 CA, CSR은 인증서 서명 요청, quorum은 필요한 승인 수입니다. Witness는 그 승인 인원에 포함되지 않습니다. [용어·작업 번호](README.md#용어와-작업-번호)

## S00

**내 역할: Independent Witness**

**검토·최종 판정:** Administrator가 S00.4에서 자료를 검토하고 S00.5에서 S01 시작 여부를 결정합니다. 행사 수행의 사전 승인권자는 별도 지정 대상이며 현재 미정입니다.

### 행사 전에 준비할 문서

| 전달할 문서 | 내가 제공할 내용 | 받는 사람 |

자료 2 전체는 Administrator가 취합합니다. 기술 시험 보고서는 작성하지 않습니다.

**별도 작성 없음.** 관찰 범위·접근 방법이 달라졌으면 시작 전에 Administrator에게 알립니다. 실제 관찰 가능 여부는 S00.1에 적습니다.

**Root 키 생성** · [열 기록지](../records/s01-root-key.md#independent-witness)

S00 종료 후 S01.1의 계획·작업 ID·해시가 제시되는 때부터 관찰합니다. S01.2에서 각 보유자의 승인/거부/미참여와 S01.3에서 보고된 실제 승인자 조합을 구분합니다. 직접 암호학적 검증을 대신했다고 기록하지 않습니다.

S01.3에서는 Administrator의 승인 검사 완료·활성화 지시, 배정된 접근 담당자의 실제 조치와 결과 보고, Administrator의 접근 범위 검사·실행 가능 선언 순서를 관찰합니다. S01.4의 생성 실행·응답 저장·공개키 제시, S01.5의 독립 검사·보호 확인, S01.6의 회수 조치·검사가 이어지는지 확인합니다. 화면·자료를 볼 수 없거나 입회가 끊기면 즉시 호출 번호·시각·누락 범위를 알리고 중단을 요청합니다.

S01.7에서는 먼저 S01.1–.6의 실제 관찰 범위·누락·이견을 보고합니다. Administrator가 S02 진행 또는 보류/중단을 실제로 선언한 뒤 내용·시각·본인 관찰 범위와 제한을 기록하고 “S01.7, Independent Witness, 선언 관찰 기록 완료”라고 보고합니다. 듣지 않은 선언을 미리 적거나 다음 호출 이후 소급해 확인하지 않습니다.

**중단·재개:** 중단 시점까지의 관찰과 한계를 보류·재개 기록지에 남깁니다. 기존 키의 잔여 검사에 다시 참석하면 승인된 재개 범위·시작/종료·본인이 실제 본 추가 작업만 기록합니다. 부재 중의 생성·접근 회수는 사후 관찰 서명으로 메우지 않습니다.

**기록:** `Independent Witness`란에 관찰 시작/종료·범위·일탈/중단·본인 확인, 실제 판정 선언·시각과 기록 완료 시각을 남깁니다. 기술 결과는 Administrator가 검사하는 것을 관찰한 범위로 구분합니다.
