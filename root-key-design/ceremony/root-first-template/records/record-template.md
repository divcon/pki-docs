# Root와 First ICA 세레모니 — 수행 기록 양식

미작성 양식입니다. 실제 행사 시 이 파일을 같은 `records/` 안의 회차별 사본(예: `session-01.md`)으로 복사합니다. 실제 시각·결과·판정·서명은 수행 중 또는 수행 후 확인한 사실만 기록합니다.

- 행사 ID·승인본은 [메인 스크립트](../script.md#행사-정보)와 일치시킵니다. 기준 묶음은 [승인본 목록](../preparation.md#승인본-목록)에서 식별합니다.
- S02·S04·S05는 각각 「작업별 승인과 서명 기록」 표를 복사해 작성합니다. 키 생성은 S01/S03마다 식별자·속성·공개키·접근 회수 증거를 남깁니다.
- 보류 시 당시 수행·입회 기록을 서명해 고정하고, 임시 종료 기록도 별도 서명합니다. 다음 회차는 이전 기록과 서명·증거 목록을 참조하며 관찰하지 않은 범위를 사후 서명하지 않습니다.
- 승인 스크립트와 이미 서명한 기록을 덮어쓰지 않습니다. 실제 서명·민감한 로그 원본은 지정 저장소에 보관하고 이곳에는 필요한 참조를 남깁니다.
