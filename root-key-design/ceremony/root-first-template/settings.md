# Root와 First ICA 세레모니 — 설정

작성 중 · 행사 기준은 [메인 스크립트](script.md)입니다. 실제 값과 선택 근거를 채우고, 승인된 버전을 [승인본 목록](preparation.md#승인본-목록)에 고정합니다. 샘플의 가상 값은 복사하지 않습니다.
