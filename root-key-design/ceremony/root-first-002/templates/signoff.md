## 확인·서명 요점

**확인 문구:** “위에 식별된 실행 부록을 포함한 스크립트와 수행 기록·증거 목록을 확인하고 서명합니다. 본인의 실제 수행·관찰 범위에서 절차 준수 여부를 표에 표시했으며, 일탈·미수행·관찰 제한은 참조한 기록에 남겼습니다.”

- **범위:** Administrator는 진행·검증·기록, Crypto Officer는 실행·본인 승인, Custodian 2·3은 각자의 승인·참여, Witness는 독립적으로 직접 관찰한 단계·시간·방법을 적는다.
- **판정:** 해당 범위 준수/일탈 있음/확인 불가와 관련 기록을 적는다. 관찰·승인하지 않은 작업을 본인의 확인 범위로 쓰지 않는다.
- **서명:** 실행 부록의 버전·해시를 포함한 서명 대상 정보를 모두 채우고 실제 파일과 대조한다. 실제 참여자와 입회자 전원이 각자 한 번 자필 또는 전자 서명한다. 접근 담당자가 겸임이면 본인 행에 접근 작업을 포함하고, 별도 인원이면 추가 행에 서명한다. 추가 참여자가 더 있으면 행을 늘린다. 이름 입력만으로 서명을 대신하지 않으며 작업별 사전 승인 서명도 별도로 남긴다.
- **보관:** 서명본과 식별된 스크립트·실행 명령·수행 기록·원문 증거를 함께 보관한다. 전자 서명은 검증 자료도 보관한다. 서명 후 추가 사실은 원본을 수정하지 않고 후속 기록으로 연결한다.
